Bu HTML dosyası yalnızca arayüzdür. CV oluşturma, giriş ve otomasyon için Python uygulamasının çalışması gerekir.

Çalışan Joblane’i aç ↗
Windows: Önce setup-windows.cmd, sonra start-windows.cmd.
Mac: Start Joblane.command dosyasını aç.
Telefon: Kendi Tailscale HTTPS adresini kullan.

Sunucu açıksa yukarıdaki bağlantıdan devam edebilirsin. Bu dosyayı açmak Python sunucusunu başlatmaz.
